# Licenses index

This directory intentionally contains no repository-wide license grant.

Existing mod-local license files remain at their original paths and keep their
original scope. See [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) for the
inventory and [LICENSE-SCOPE.md](../LICENSE-SCOPE.md) for the boundary rule.

Do not copy a mod-local license into this directory or use it as a license for
a different mod, translation, tool, archive, executable, image, or game asset.
