# Crusher Cleave Indicator

在碾壓者橫掃攻擊時顯示範圍圓環：黃色表示攻擊預警，紅色表示攻擊動作。可選擇讓黃色圓環常駐顯示。

## 踉蹌中斷

碾壓者的橫掃攻擊被踉蹌打斷時，MOD 會移除該次攻擊的提示圓環，並取消尚未完成的圓環載入。若啟用了常駐黃色圓環，仍會顯示常駐提示。下一次攻擊會重新建立自己的提示，不沿用已中斷的狀態。

本機與遠端碾壓者都使用遊戲的踉蹌動畫事件辨識中斷；遠端事件索引無法辨識時，不會推測為踉蹌。此功能由 `crusher_attack_indicator` 自行處理，無須安裝其他踉蹌偵測 MOD 或調整 MOD 載入順序。

## 設定

- **啟用**：開關本 MOD 的提示。
- **一律顯示黃色圓環**：在非攻擊期間也顯示黃色範圍。
- **圓環半徑**：調整提示範圍。
- **黃色警告／紅色攻擊圓環顏色**：分別調整顏色分量。

關閉 MOD、關閉提示設定，或碾壓者死亡、離開場景時，相關圓環與等待中的載入會清除。
