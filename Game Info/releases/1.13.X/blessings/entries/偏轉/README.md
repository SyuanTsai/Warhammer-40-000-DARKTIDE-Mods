# 偏轉(Deflector)

[祝福目錄](../../README.md)｜[來源與公式](SOURCE_INDEX.md)

<img src="https://github.com/user-attachments/assets/ce4a8d9f-8ffc-4194-bfbd-ef4db317aaf5" width="72" height="72" alt="偏轉祝福圖示">

- **觸發方式**：持用有偏轉的烈焰力場巨劍，按住格擋即可啟用遠程格擋。

- **I–IV消耗降低**：格擋消耗分別降低22.5%／25%／27.5%／30%，作用於近戰與遠程格擋。

- **遠程角度**：攻擊者須位於面向左右各約59.4度內，合計約118.8度的正面扇形；角度依你與攻擊者的位置計算。

- **攻擊分類**：只開放遊戲判定為遠程、且可被格擋的攻擊；爆炸、電弧和標為不可格擋的攻擊不會因偏轉而納入。

- **切換武器**：切出烈焰力場巨劍後，停止遠程格擋與此祝福的消耗減免；重新持用時恢復。

- **疊層與冷卻**：沒有疊層、持續時間或觸發冷卻。

- **型號差異**：烈焰力場巨劍 誓約 Mk VI／Mk VIII，共用同一效果與等級數值。

## 計算與算例

- **IV級消耗算例**：同一合格格擋原本扣1點體力，其他條件不變且沒有額外支付方式時，偏轉 IV級乘0.70，改扣0.70點體力，降低30%。

- **乘算例**：若原本已乘另一個0.80的格擋消耗倍率，再套偏轉 IV級，合計 `0.80 × 0.70 = 0.56`，總減免44%，不把20%與30%直接相加。

- **角度算例**：攻擊者在面向右方50度內屬於有效遠程格擋角度；在右方70度則超出範圍。左右各約59.4度，合計約118.8度。

- **分類算例**：一個爆炸類型攻擊即使來自正面遠處，也不會因偏轉而成為可格擋的遠程類型。

## 遊戲描述勘誤

- **遠程格擋**：本體未列正面扇形與攻擊本身可格擋的條件。

- **消耗減免**：作用於格擋消耗，並不增加最大體力。
