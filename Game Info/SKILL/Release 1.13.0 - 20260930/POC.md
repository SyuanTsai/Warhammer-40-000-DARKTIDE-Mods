## 冷卻代表：veteran_replenish_grenades

選擇原因：不同手雷能力選用不同補給週期、缺額才開始計時、滿額重設、嚴格時間比較，並牽涉共用能力資源上限。詳細來源及正式描述見[職業文件](TALENTS_Veteran.md#veteran_replenish_grenades)。

以下為直接閱讀執行邏輯後的手動狀態推演，未執行 Lua 或遊戲測試。設破片手雷週期 60 秒，缺額首次被更新函式觀察到的時間為 100 秒。

| 邊界案例 | 原始碼推導預期 |
|---|---|
| 首次缺 1 顆，t=100 | 設截止時間 160；本次不補給 |
| t=159.999、t=160 | 均不補給，因使用 `next_grenade_t < t` |
| 首次更新時的 t>160 | 補 1 顆，清除計時；實際時刻取決於更新排程 |
| t=130 又投出 1 顆 | 缺額變大，但既有截止時間仍為 160 |
| t=140 拾取補滿，之後缺額 | 觀察到滿額便清除進度；新缺額重新計滿週期 |
| 補 1 顆後仍缺額 | 下一次更新才設定下一個截止時間，不一次補滿、不追補多個逾期週期 |
| 改以穿甲手雷首次缺額 t=100 | 截止時間 190；相同嚴格大於規則 |
| 沒有手雷能力 | 清除 next_grenade_t 與缺額狀態 |

驗收：當前節點、天賦、週期設定、更新邏輯、恢復資源的呼叫流程與上限均已直接核對。內部 `name` 的 60 秒及通用後備值 75 秒不等於所有手雷實際週期。核心靜態機制完成；遊戲內顯示、音效、排程延遲及運行中切換配裝的存續期間未實測。

選擇原因：比對殘留距離文案與實際受擊時間條件，並追到傷害加算階段。正式說明與來源見[職業文件](TALENTS_Veteran.md#veteran_ranged_power_out_of_melee)。

## 疊層代表：振奮擊倒

選擇原因：遠程弱點擊殺條件、韌性恢復、連乘減傷、共同計時及逐層衰退。正式說明與永久來源見[振奮擊倒](TALENTS_Veteran.md#veteran_replenish_toughness_on_weakspot_kill)。

| 手動推演案例 | 預期 |
|---|---|
| 遠程弱點命中但未擊殺 | 不觸發 |
| 符合條件的擊殺，最大韌性100、目前95、無恢復加成 | 實際補5；仍增加一層減傷 |
| 最大韌性100且已滿 | 實際補0；仍增加一層減傷 |
| 有效層數1／2／3 | 韌性受傷倍率0.9／0.81／0.729 |
| 三層，最近一次觸發時間100 | t=108尚未到期；首個t>108的更新降二層並重新計時 |
| 內部計數4，但有效層數3 | 不提供第四層減傷；到期同輪更新可移除溢出計數並降至二層 |
| 持續符合條件的擊殺 | 持續刷新共同計時，效果仍最多三層 |

驗收：核心原始碼與共享疊層邏輯已由主控直接核對；曾發現子代理將溢出層誤述為每幀移除一個，經檢查「多索引共用同一效果物件」後修正。此紀錄說明子代理摘要不能取代原始碼證據。全部案例為靜態推導，未執行 Lua 或遊戲測試。

## 能力升級代表：掩護射擊

選擇原因：區分多一次充能、每次成本增加、共用資源池、恢復時間與配裝分支。來源與完整推導見[掩護射擊](TALENTS_Veteran.md#veteran_combat_ability_extra_charge)。

| 手動推演案例 | 預期 |
|---|---|
| 只有本升級，沒有其他成本或恢復加成 | 上限由1變2；每次成本40×1.33=53.2 |
| 資源0，連續按每秒1恢復 | 約53.2秒可用1次、106.4秒補滿2次；實際以更新及精度判定 |
| 第二次使用前已有部分恢復進度 | 扣除一次成本，已累積的小數進度保留 |
| 恢復已到容量上限 | 不持續儲存超額資源 |
| 重生或配裝令上限變動 | 共用程式有補新增容量與重生例外，不能一概視為送滿充能 |

驗收：節點、基礎能力、兩項屬性、成本及容量公式、消耗起點與恢復流程均由主控直接核對。未進行遊戲內測試；不把53.2秒宣稱為所有配裝的固定觀察值。

## 傷害分類與加算代表：優越情節

選擇原因：追蹤天賦與效果使用不同識別碼的引用關係，區分精英與專家分類，確認傷害加算位置。正式說明及永久來源見[優越情節](TALENTS_Veteran.md#veteran_increase_damage_vs_elites)。

| 手動推演案例 | 預期 |
|---|---|
| 精英目標，其他同階段加成為零 | 傷害加算合計由 1 變為 1.15 |
| 只有專家分類、沒有精英分類 | 此天賦不增加傷害 |
| 目標缺少敵人分類資料 | 此天賦不增加傷害 |
| 近戰或遠程命中精英，未命中弱點且不是致命一擊 | 此項分類加成仍可成立 |
| 精英目標，同階段原已有 25% 加成 | 合計由 1.25 變 1.40，不是 1.4375 |
| 連續命中同一精英 | 不因命中次數累積更多層數 |

驗收：當前節點、天賦引用、被動效果、目標分類判定、加算型別及共用傷害結算均已直接核對。案例為靜態手動推演，未執行 Lua 或遊戲內測試。五個樣本已完成，依使用者指示暫停，先調整描述規則。
