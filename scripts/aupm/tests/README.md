# AUPM 相容性回歸測試

在 Repository 根目錄使用 LuaJIT（Lua 5.1）執行：

```powershell
luajit scripts/aupm/tests/test_aupm.lua
```

測試直接載入 AUPM 的正式程式，以獨立的 DMF／遊戲介面替身驗證新版與舊版冷卻 API、本人及隊友技能統計、多次充能、任務計時尚未就緒、HUD 顯示與任務重置。無須啟動遊戲或安裝 MOD。

預期結果：9 個案例全部通過。這些測試不包含遊戲引擎、網路同步或畫面排版的實機驗證。

實機驗證：在 1.13.1 啟用 AUPM，進入任務並施放戰鬥技能，確認本人使用次數增加、每分鐘使用率及冷卻秒數可顯示；請隊友施放技能並確認隊友面板也更新。返回晨星號後統計應隱藏，下次任務應重新計數。
