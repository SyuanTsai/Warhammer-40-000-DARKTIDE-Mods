# Game Info 技能與對話流程分離

使用者確認目前十組分頁對話的設計，要求寫回 `AI Prompt/Game-Info-Workflow.md` 並分開 SKILL 與對話職責。

- `Game-Info-Workflow.md` 改為流程入口，提供兩類提示詞、輸出位置及紀錄歸屬，不集中兩套完整規則。
- `Skill-Info-Workflow.md` 保存原本完整技能規則，包括證據、機制、公式、玩家說明、圖示、版本、逐技能提交與驗收。除分工說明、入口連結及自我路徑引用外，逐字核對原文件完整保留。
- `Dialogue-Text-Workflow.md` 獨立維護官方事件、字幕配對、角色頭像、來源及聊天頁，補齊已確認網站結構、配色、01–10 編號、可點中英文標題、右上角單一語言切換及驗收方式。頭像保存規則直接收在對話流程，無須引用技能流程。
- 修正兩份技能百分比盤點文件的三處描述規則引用；共用工具與紀錄入口分別提供技能、對話流程連結。
- 技能、對話及網站交付紀錄沿用既有各自目錄，共用 INDEX 只登記入口。完整來源與雲端封存保持既有位置；本次為文件調整，不執行 production code bootstrap 或網站發布。
